⚡ Cơ Chế Kỹ Thuật Kết Nối 3 Nền Tảng CDE Đám Mây Cloud Integration
1. AUTODESK ACC APS / Forge API
  • Giao thức: Autodesk Platform Services (APS) OAuth 2.0 2-Legged Authentication.
  • Dữ liệu đẩy: Đồng bộ trạng thái thi công vào Custom Properties của BIM Viewer; tự động tạo danh sách Issues / Submittals theo mốc WBS P6.
  • Điểm mạnh: Worksharing Revit cực mượt, kiểm duyệt thiết kế Design Collaboration.
2. TRIMBLE CONNECT .NET SDK / REST
  • Giao thức: Trimble Connect Workspace REST API & bộ thư viện C# Trimble.Connect.Client.
  • Dữ liệu đẩy: Gán trạng thái lắp dựng (Fabrication / Erected) vào GUID cấu kiện; tự động sinh danh mục Tasks / ToDo.
  • Điểm mạnh: Tối ưu tuyệt đối cho Kết cấu thép (Tekla), bản vẽ Shop & OpenBIM IFC nhẹ.
3. DALUX BUILD Dalux Build API
  • Giao thức: Dalux Build REST API qua HTTPS Header X-API-KEY & JSON payload.
  • Dữ liệu đẩy: Tự động tạo Tasks thi công cho thầu phụ; kích hoạt sẵn Checklists nghiệm thu số theo tiến độ hoàn thành trong SQL.
  • Điểm mạnh: Ứng dụng hiện trường (Mobile BIM), nghiệm thu và quản lý lỗi thực tế tốt nhất.

Quy Trình 3 Bước Tự Động Hóa Dành Cho Kỹ Sư BIM & Quản Lý Dự Án:
Bước 1: Chọn Nguồn SQL
Trích xuất dữ liệu từ tiến độ P6 (PPMDBSQLite.db), BOQ bóc tách Revit hoặc bảng tiến độ rút gọn.
Bước 2: Tích Chọn Đám Mây
Chọn đẩy lên ACC (Issues thiết kế), Trimble (Trạng thái thép), hay Dalux (Nghiệm thu công trường).
Bước 3: Nhấn [Sync to Cloud]
Hệ thống xử lý batch request đa luồng, đẩy hàng trăm công tác lên đám mây trong vòng 5-10 giây.
