1. Cấu Trúc Thư Mục & Trạng Thái Dữ Liệu (ISO 19650 Common Data Environment) Tải file lên thư mục có sẵn của dự án để xem, tải về và gộp (combine) mô hình. Quy hoạch 4 phân khu dữ liệu chuẩn ISO 19650:
  • WIP (Work in Progress): Đang thực hiện nội bộ từng bộ môn.
  • Shared: Chia sẻ phối hợp liên bộ môn (Kiến trúc, Kết cấu, MEP).
  • Published: Đã duyệt chính thức phát hành cho TVGS, Nhà thầu thi công.
  • Archive: Đóng băng lưu trữ lịch sử pháp lý của dự án.
 • ACC: Naming Standard (ép chuẩn tên file, sai chuẩn rơi vào Holding Area).

• Trimble: Folder Template & Releases.

• Dalux: Box Pro Published Folders.
2. Ma Trận Phân Quyền (Permission Matrix) Đăng nhập bằng tài khoản được cấp quyền sẵn để truy cập file dự án. Phân quyền ma trận theo Vai trò (Role) và Đơn vị (Company):
  • Thầu phụ MEP: Chỉ thấy thư mục riêng của mình (View/Upload).
  • Chủ trì Kết cấu: Quyền Edit/Manage trong phân khu WIP nội bộ.
  • Hiện trường / QS: Quyền View Only tại thư mục Published đã duyệt.
 • ACC: 5 Permission Levels (View ➔ Download ➔ Markup ➔ Upload ➔ Edit/Manage).

• Trimble: User Groups & Access Control.

• Dalux: User Roles & User Groups.
3. Luồng Phê Duyệt Hồ Sơ (Approval Workflows) Xem bản vẽ 2D/3D trên viewer để kiểm tra kỹ thuật và phản hồi thủ công. Thiết lập luồng trình ký tự động trên mây:
Modeler nộp file (WIP) ➔ Chủ trì bộ môn kiểm tra (Review) ➔ BIM Manager phê duyệt (Approve) ➔ Hệ thống tự động copy file sang thư mục Published kèm chữ ký số/con dấu Approved. 		• ACC: Reviews Module (Setup luồng duyệt 1, 2, 3 bước; Auto-copy to Published).

• Trimble: Releases & ToDos Tracking.

• Dalux: Comments, Tasks & Release Flow.
4. Quản Lý Lỗi & Phối Hợp (Issue / BCF Management) Bật tắt các model bộ môn để mắt thường soi va chạm (Visual Clash). Quản lý vòng đời phối hợp (Issue Lifecycle):
Khoanh vùng đám mây (Markup), ghim Issue gắn tọa độ camera 3D, chỉ định đích danh cá nhân phụ trách, ấn định hạn xử lý (Due date) và đồng bộ 2 chiều về phần mềm tác nghiệp (Revit/Tekla/Navis) bằng chuẩn mở BCF. 		• ACC: Issues & Model Coordination.

• Trimble: BCF Topics Sync (mở thẳng góc nhìn Revit/Tekla).

• Dalux: BIM Issues & Capture Tasks.

1. Không thừa nhận thụ động

Tránh câu: "Em mới chỉ dùng xem file và combine". Hãy trả lời: "Tôi đã khai thác CDE giải quyết bài toán cốt lõi nhất: Federated Model, đối chiếu 2D/3D kiểm duyệt Shop Drawing và bóc tách BOQ."

2. Nhấn mạnh ISO 19650

Khẳng định vai trò Trưởng phòng BIM là ra đề bài quy trình: quy hoạch 4 vùng dữ liệu (WIP - Archive), ma trận phân quyền Role-based, và luồng duyệt tự động (Admin kỹ thuật hãng luôn hỗ trợ setup).

3. Tích hợp Open API & CSDL

Đưa ra định hướng vượt trội: Kết nối CSDL SQL nội bộ với Cloud CDE thông qua Open API và chuẩn BCF để tự động hóa tiến độ, chất lượng và phục vụ Dashboard Ban Lãnh đạo.
